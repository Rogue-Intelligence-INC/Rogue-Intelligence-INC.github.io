## What this laboratory is

Rogue Intelligence builds **structure-first** systems: persistent state, decision gates, and auditability that do not collapse into a single black-box model or vendor badge.

| Principle | Meaning |
|-----------|---------|
| Structure outside the LM | Agent reliability state is not only prompt text |
| Named protocols | Claims carry protocol IDs, pass bars, and honest bounds |
| Separate SKUs | ValhallaBase ≠ Yaksha ≠ Wave/OS — shared lineage, distinct roadmaps |
| Self-funded independence | No institutional grant dependency to date; solo engineering |

## What this laboratory is not

- Not a Mem0 / generic memory-API clone  
- Not a claim of LoCoMo SOTA versus commercial memory products  
- Not a Transformer-replacement consumer SKU  
- Not investment advice; financing notes live only on the [About]({{ '/about/' | relative_url }}) page
