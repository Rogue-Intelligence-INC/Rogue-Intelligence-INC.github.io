Sub-project · Windows · 28 October 2026

A small shell that enhances an existing model.

This is a currently usable Windows program. It attaches an instruction-tuned language model and adds a knowledge library, a conversation list, screen reading, and computer control that stays off until it is switched on. The main project is Valhalla.

Place in the laboratory

Valhalla is the research program: it incubates a structure-trainable body from an empty session. This page is a sub-project. The shell does not implement that cultivation. It takes a model that already exists, today a Qwen2.5 Instruct checkpoint, and gives it a Windows workplace.

What it does today

  1. 01
    Chat

    A conversation list sits on the left. New chat adds a thread. Right-click deletes one. The executable is Valhalla.exe.

  2. 02
    Knowledge

    Handwritten notes stay one fact per line. An import entry takes industry files in txt, md, csv, tsv, json, jsonl, html, xml, rtf, log, docx, xlsx, pptx, and pdf. Imported text is marked pending review. A question retrieves matching passages.

  3. 03
    Screen

    Recognize steps the window aside, captures the desktop behind it, reads the image with Windows OCR, and lists UI Automation controls with screen coordinates.

  4. 04
    Control

    Computer control is off until the switch is on. Allowed actions are read screen, click, click by recognized text, move, type, key, and scroll.

  5. 05
    Model and strategy

    The model panel lists Qwen2.5 Instruct sizes. Strategies in the interface are faithful retrieval, hybrid multiple choice, follow-up session, and multi-hop.

What it calls

Turns go to valhalla_base.exe when that runtime is installed beside the shell. The runtime is the Valhalla research checkout. It is not shipped in the Windows repository. Model weights are read from the machine’s model directory. They are not in the repository either.

Repository: valhalla-windows.

Bounds

This shell enhances an attached model. It does not start an intelligence from an empty session. That claim belongs on the Valhalla page, and it has the limits written there.
