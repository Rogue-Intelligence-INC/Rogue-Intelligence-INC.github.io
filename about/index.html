Rogue Intelligence Inc.

An independent laboratory for structural intelligence, exact mathematical exploration, experimental cryptography, and rule-driven machines.

Name

This site uses Rogue Intelligence Inc. Older pages of this website, and license headers in the repositories, print Rogue Intelligence LNC. That spelling is historical. It has not been silently rewritten inside those repositories.

Authorship

The previous public about page, and the Wave license lines, name Jouly (ZHUOLI MA) as the author of this body of work. The same page dated the work from 5 April 2025 and described it as independent. This site keeps that credit and does not add a biography beyond it.

What is public, and under which terms

  • Valhalla Unified Core, the technical mirror, and the Valhalla runtime: proprietary. No open-source license is granted there.
  • Yaksha Cipher 1.0.0, local crate: proprietary, not published to crates.io. The manifest’s GitHub URL was not a public repository when this site was written.
  • Wave, Wave-C, Wave-ASM, Wave-BIN: MIT, with the LNC spelling still in the copyright line.
  • Val-Crypt: MIT, in its public repository.
  • S-WIND: the engineering report says MIT. No public repository was confirmed, and the manuscript is not posted here, so this site does not offer the source.

Licensing conversations go to licensing@rogue-intelligence.com. Research collaboration uses the same address, or GitHub, via the contact page.
