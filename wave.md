## Wave {#wave}

Public technical framing (from laboratory manuals):

| Property | Description |
|----------|-------------|
| Aim | Systems language with Fate autonomy and hybrid UI surfaces |
| Compilation | Toward native (x86-64 ELF64 in documented v4 manuals) |
| Memory idea | Fate + Quattro pools (capacity / association / parallel / base) |
| Role | Experimental substrate and conceptual ancestor — not the ValhallaBase sales SKU |

Wave documents live in monorepo trees such as `wave-v4-backup/docs/WAVE_LANGUAGE_MANUAL.md` and related `wave/` toolchains.

## Val-OS {#valos}

**Val-OS** packages Wave runtime ideas into OS-shaped experiments:

- Fate as a central decision engine (scheduling, allocation, collapse / re-optimize loops)  
- Quattro memory pools (BlackHole · MeshBrain · MultiNova · BaseForce)  
- Fate Organizer — intelligent file organization demos (“Hub in reverse”)  
- Desktop environment sketches (files, terminal, notepad, browser shells)

See monorepo: `val-os-v5/` (and archived `val-os*` trees). Treat as **research OS demos**, not a shipping consumer OS commitment on this site.
